
# Experiment 1: Git Operations

## Aim
To create a Git repository and perform basic Git operations.

## Operations
1. Create a repository
2. Add and commit files
3. Create branches
4. Merge branches
5. Push and pull changes
6. Fetch remote updates
7. Reset and revert changes
8. Clone a repository
9. Fork a repository

## Result
Successfully created a GitHub repository and practised repository management operations.
